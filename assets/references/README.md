# Design reference

`system-analysis-design-reference.pdf` is a privacy-edited copy of the supplied
`System Analysis lec 1,2,3,4.pdf` (190 pages).

SHA-256: `1fdcad6b428d7daa0d618b0c49db6dc075ea3678efa93153b815cd289c75bcff`.

Instructor names were removed from four cover pages and from accessibility
text. Document metadata was cleared. The other 186 page renders are unchanged;
the four edited pages differ only where the instructor names appeared.

Use it with the `design` attachment role. Its course content is not evidence
for a different lecture. Preserve the original PDF when extracting a style.
See the repository's `NOTICE` for the distinction from the code license.

The adjacent `../styles/blueframe-lecture.json` adapts selected layout tokens.
It uses installed Arial and supplies no font binaries or original backgrounds.
The PDF renderer uses flowing cards; editable PowerPoint uses its native layout.
